# PSF Organizers Kit Contributing Guide

## Contributing to the PSF Organizers Kit
Thank you for your interest in contributing to the PSF Conference and Community Organizers Kit!
This Kit is a community-driven resource designed to help people start, organize, and strengthen Python communities, conferences, meetups, and other Python-related events

We believe that knowledge and experiences from community organizers around the world make this resource more useful. You do not need to be a Python developer to contribute!

## Ways to Contribute
There are many ways to help improve the PSF Organizers Kit. You can contribute by:
- Improving documentation: Fix typos, clarify instructions, improve existing content, or make information easier to understand.
- Sharing organizing experiences: Contribute practical lessons, recommendations, and approaches from organizing Python communities, conferences, meetups, and events.
- Adding resources: Suggest useful templates, checklists, guides, tools, and other resources that organizers may find helpful.
- Identifying gaps: Suggest topics or areas that are missing from the toolkit.
- Improving accessibility and inclusion: Help ensure that the toolkit supports organizers with different backgrounds, experiences, resources, and accessibility needs.
- Reporting issues: Identify outdated information, broken links, unclear instructions, or other problems.
- Reviewing contributions: Help review proposed changes and provide constructive feedback.

Not sure where to start? Browse the existing issues or open an issue to share an idea.

## Before You Start
Before making a contribution:
- Check the existing documentation to see whether the topic is already covered.
- Search the issue tracker to see whether someone has already suggested the same improvement.
- For significant changes or new sections, open an issue to discuss your idea before investing time in writing.
- For small improvements, such as fixing typos or correcting broken links, you can submit a pull request directly.
- When contributing, please make sure the contributions are small and manageable, allowing time to discuss and guide contribution styles. This kit is made by volunteers, so please be patient when it comes to reviewing pull requests. 

We encourage discussion and collaboration so that contributions remain consistent with the goals of the toolkit.

## AI Contributions
You can use AI to help work with wording and ideas, but please do not use AI to generate large blocks of content. Communities are made up of the people within them, and we want this guide to reflect the many unique people who worked together to build this resource.
